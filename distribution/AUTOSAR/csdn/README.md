# CSDN · AUTOSAR 入门

- 单份分发版在 `../articles/<slug>.md`（贴之前用 `--platform csdn` 现生成，链接指向 CSDN 已发版本）
- 「创作」→ Markdown 编辑器粘贴；标题框填 frontmatter 的 `title`；图片拖入自动转存
- 勾选 AI 生成内容标识；百度收录约 1~3 天生效（Bing 搜「UDS 诊断」首页 7/10 是 CSDN，收录是实打实的）
- 发出后：URL 登记 `../links.json` 的 `csdn` 键 → 下次生成自动回填
