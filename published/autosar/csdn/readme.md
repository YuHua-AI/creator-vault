- 贴稿：`node .claude/skills/write-article/scripts/gen-dist-versions.js published/autosar/<篇名> --platform csdn | pbcopy`，粘贴到 Markdown 编辑器（链接指向 CSDN 已发版本）
- 「创作」→ Markdown 编辑器粘贴；标题框填 frontmatter 的 `title`；图片拖入自动转存
