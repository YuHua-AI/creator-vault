# CSDN · AUTOSAR 入门

- 准自动（推荐）：`node .claude/skills/write-article/scripts/push-platform-draft.js published/autosar/<篇名> --platform csdn`
  自动填标题/贴正文/拖图，停在发布前；首次运行在打开的窗口里登录一次，会话持久化
- 手动兜底：`node .claude/skills/write-article/scripts/gen-dist-versions.js published/autosar/<篇名> --platform csdn | pbcopy`，粘贴到 Markdown 编辑器
- 勾选 AI 生成内容标识；百度收录约 1~3 天生效（Bing 搜「UDS 诊断」首页 7/10 是 CSDN，收录是实打实的）
- 发出后：URL 登记 `../links.json` 的 `csdn` 键 → 下次生成自动回填
