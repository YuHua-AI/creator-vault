# GitHub 周榜 / 周精选帖图 · 生产规则

本系列做期过程中沉淀的硬规则，持续追加。冲突时以本文件为准。

两种期型（详见 SKILL.md）：**周榜**＝涨星排名 9 图（data.json + gen-*.js 产线）；**周精选**＝主题策展手写卡片（无 data.json，首例 `drafts/github/weekly-20261114/`）。下面未标注期型的规则两者通用，标〔周榜〕的只约束排名期。

## 内容规则

- **帖图＝微信「图片消息」（newspic）**，不是图文文章。图为主文为壳：article.md 只留开场 2~3 行 + 图连排 + 收尾互动，信息量全部做进卡片，正文不重复卡片内容（周榜 9 图；周精选图数随主题定）
- **子图标题用项目名**（repo 原名，如 `dsh-superagent-prototype`），不用中文概括；标题下一行小字＝`作者 · 语言`（不重复仓库名）
- **一句话 pitch** 是每张卡的钩子，绿色霓虹字；三段正文标签固定档案风：`项目速览` / `核心玩法` / `适用人群`，各 2 行
- **每行文案 ≤40 字**（fs27 下不溢出画幅）；中英混排行（如 `Study → Build → Check → Ready`）出图后必须重点核查
- 文案口吻：说人话、面向公众号读者，有钩子但不吹；负责任地转述（研究原型就写研究原型）
- 星数（总星标/周增长）**只以 `tools/github-weekly-rank` 当周文件为准**，不凭印象、不手算〔周榜〕
- 首图为 `cover.jpg`（信息流封面即它），8 行榜单按周增长降序、序号 01~08〔周榜〕

## 版式规则

- **全部 1350×1800 竖版**，主图与子图同画幅成套（主图也是竖图；周榜 9 张，周精选随主题）
- **图标必须贴题**：每个项目一个专属图标，编码项目本质（如 skillfile＝SKILL.md+双勾门禁、remote＝手机→显示器），不用通用图形；新图标进 `scripts/icons.js` 共享库
- 长项目名（>16 字符）标题自动降一档字号（72→54），防撑爆〔周榜，gen-*.js 自动处理；周精选手写时同规则自查〕
- 三档排名视觉强调：NO.01~03 绿色 + 发光，04~08 蓝灰〔周榜〕
- 生成器脚本是**唯一版式源**：改版式＝改 `scripts/gen-*.js` 并 commit，下期自动沿用；**严禁手改 JPG**——有问题是改 data.json / icons.js（周精选则改 SVG 源）后重新生成渲染

## 管线规则

- 标题 ≤20 字（frontmatter `post_title`），文案 ≤1000 字纯文本——微信图片消息硬限制（2026-11-14 实测修正：原记 32 字，实际 20）
- 推送用 `image-post` 的 `push-image-post.js`（按正文图序传永久素材，首图即封面），不用 write-article 的 push-draft.js
- 出图后逐张视觉自检（截断/重叠/溢出），全过再交人工审图
- 改动先积累、收尾统一 commit；凭据永不入库
