# 写作规则

文章写作规则的沉淀处：新规则先落这里，起草 / 改稿 / 推草稿前先读本文件。`write-article` skill 以此为准。

## 标题

- **正文不以一级标题（H1）开头**：标题放 frontmatter `title`，发布时进公众号标题栏 / 各平台标题位，正文再放 H1 会重复显示。正文小标题一律从 `##` 起。
  （来源：2026-11-10 推草稿时发现《告别传统 DDNS》正文 H1 与公众号标题栏重复，已修正两篇存量文章）

## 文末结构（每篇固定三段式，只换内容）

正文收束句之后，用分割线 `---` 隔开，依次写两段：

1. **互动一问**：只问一个问题；征集故事（「你干过什么硬核操作」）优于征求状态（「你用什么」）——门槛越低越出评论
2. **下一篇预告 + 关注引导**：有具体下一篇就写预告（「下一篇拆 XX，关注不迷路」），没有就用系列钩子；品牌句用「零基础玩转科技工具」，不堆口号

注意：

- **不设 `##` 平级标题**（如「互动时间」）：文末段是余韵不是章节，用分割线/加粗区分即可，别抢正文收束 punchline 的戏
  （来源：2026-11-10 评审 DDNS 文结尾——平级标题截断收束情绪、双问题抬高评论门槛、关注引导缺具体钩子）

注：以上三段式是**正文**文末（公众号侧）；站外分发在正文之后另拼 `published/<专题>/footer.md`，规则见下节。

## 摘要（digest，三平台一份）

- 写进 frontmatter 可选字段 `digest:`——公众号推送（push-draft.js）优先取它，CSDN/知乎发布框手动贴同一段
- 公式：**悬念钩子（具体场景/问题）＋ 拆解对象（必须含搜索关键词，如 UDS/CAN/0x27）＋ 读者收获（一句可验证的承诺）**
- 100~150 字；忌论文腔（「本文介绍了」）；关键词必须出现——CSDN 摘要是百度收录的锚文本
  （来源：2026-11-15 CSDN 首发 AUTOSAR ① 实战）

## 站外分发 footer（published/<专题>/footer.md）

- **绝不出现公众号/微信引流**——CSDN、知乎审核红线，出现即拒；CTA 用站内「关注、收藏」
- 不放系列目录列表：系列持续更新，固定列表会过时锁篇目
- 结构：一两句系列定位（含关键词与标准号）+ 站内关注收藏引导 + 转载声明，两段以内
  （来源：2026-11-15 CSDN 首发——目录列表与公众号引流先后被要求去除）
