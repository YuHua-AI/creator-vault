# 系列插画设计规格（数字岛屿系列）

全系列配图共用一套设计语言。新图先读本文档，再手写 SVG 设计稿（存文章目录 `img-src/`），用 `scripts/render-img.js` 渲染成 JPG 到 `img/`。规格提取自 Tailscale 篇封面与插图。

## 画布

| 类型 | 尺寸 | 比例 |
|---|---|---|
| 封面 `cover.jpg` | 2848×1600 | 16:9 |
| 分节插图 `01-xxx.jpg` | 2400×1350 | 16:9 |

## 色板

| 用途 | 色值 |
|---|---|
| 背景主色 | `#0A1826`（深海军蓝） |
| 背景径向提亮 | 中心 `#16294A` → 边缘 `#0A1826`（右上）；左下柔光 `#14405E` @45% 渐隐 |
| 主描边（发光青） | `#35D0FF` |
| 次级描边（蓝） | `#3B9FE8` / `#5B8CFF` |
| 强调青绿（解法/关键词/状态灯） | `#3EE8B0` |
| 警示红（坑/错误标记） | `#DD4B4B` |
| 白色标题 | `#E8F0F8` / `#FFFFFF` |
| 次级灰蓝文字 | `#8FAECB`（地点标签）/ `#6B8299`（副标题） |
| 屏幕内填充 | `#12294D` / `#16293E` |
| 网格线 | `#132440` @35%，间距 80px |
| 胶囊 | 填充 `#0E2A4A`，描边 `#3E6E9E` 1.5px，文字 `#D6E6F5` |

字体：`'PingFang SC','Hiragino Sans GB',sans-serif`，标题 weight 700–800。

## 造型语言

- **霓虹线框风**：主体元素描边为主（stroke 3.5~4.5px，`round` 连接），极少实心填充（屏幕/身体内部用深蓝低亮度填充）
- **发光**：`feDropShadow(0 0 6~8 主色)`，同色光晕；青绿/红色元素各用同色滤镜
- **节点连线**：贝塞尔平滑曲线 + 端点白色空心圆（r≈8~10，白描边）；线上点缀青绿实心小圆（音乐/数据点）
- **粒子**：6~10 个小圆点（r 2~4，`#7FA8D0`，透明度 0.2~0.5）散布空白处
- **全图仅三种高饱和色**（青、蓝、青绿，坑图加红），其余一律低饱和灰蓝

## 构图模板

**封面（左图右文）**：
- 左 ~52% 图形区：场景化拓扑（设备 + 连线 + 波纹），底部可加发光横线当「桌面/书架」
- 右 ~45% 文字区（左对齐统一边缘）：
  1. 顶部胶囊：`数字岛屿 · <主题>篇`（30px，letter-spacing 6）
  2. 主标题：英文关键词（如 Tailscale / AirPlay），150px，`#35D0FF→#5B8CFF` 线性渐变
  3. 副标题：中文四~六字，94px 白色粗体
  4. 卖点行：40px，白色为主，关键词用青绿强调
  5. 三个胶囊按钮横排（h 64，30px）
  6. 右下落款：`屿华AI · YuHua-AIPlay`（24px `#8FAECB`）
- 地点标签（STORE · 曲库 这类）用全大写 + letter-spacing 3~5

**分节插图（横链 + 金句）**：
1. 顶部居中胶囊：`<英文标签> · <小节关键词>`（如 `ROLES · 铁三角分工`、`SETUP · 配置三坑`、`SCENE · 声音跟着人走`）
2. 中部横向元素链：2~4 个主体沿垂直中线（y≈45%~55%）一字排开，节点下方「白色标题 36px + 灰蓝副标题 28px」；坑图用红色短横条（90×7 圆角）作坑标记
3. 底部居中金句：46px 粗体，白句 + 青绿强调词收尾（如「NAS 管存，**音箱管唱**」）
4. 上下留白 >60%，视觉动线从左到右讲一句话

## 可复用图形（坐标以 2400×1350 为例，按需平移缩放）

- **NAS 服务器**：两层圆角横条（320×80，间距 16）叠放；左端 3 条插槽短线，右端青绿状态灯（r 9，发光）
- **老路由小方盒**：圆角方形 220~250（rx 28），边角青绿 LED 小点，耳机孔=边上的空心圆（r 30）
- **音箱**：竖圆角矩形（230×460，rx 26），高音单元小圆（r≈46）+ 低音单元大圆（r≈84）同心分层，底部青绿电源点
- **手机**：竖圆角矩形（140×260，rx 22），顶部听筒短线，屏内青色实心播放三角
- **人物**：实心青蓝圆头（r≈42）+ 深蓝填充圆角矩形身体（rx 30）
- **声波/投送弧**：同心半圆弧 3 档（r 递增 ~40，opacity 0.55/0.35/0.2）
- **音乐波形**：正弦样贝塞尔长线，`#3EE8B0→#35D0FF` 渐变描边

## 渲染管线

```bash
node .claude/skills/write-article/scripts/render-img.js <img-src/foo.svg> [img/foo.jpg]
```

- SVG 的 viewBox 即输出像素尺寸；系统 Chrome（`channel:'chrome'`）headless 渲染，JPG quality 92
- SVG 源码留在文章目录 `img-src/`，可改可重渲（正文只引用 `img/*.jpg`）
