# AUTOSAR 系列视觉规格（三风格分工体系）

三套风格按**图的功能**分工，不在同一张图内混用。风格源头是 ① 篇 `img-src/sample-{a,b,c}-*.svg`，新图照抄对应样张的色板与造型语言。

## 分工规则

| 图的功能 | 风格 | 例 |
|---|---|---|
| 封面、架构/拓扑/分层/流程等**结构图** | **A 工程蓝图** | 封面、三层分工、寻址拓扑、服务地图、DCM 流水线 |
| 一段**报文交互的分析**（请求-应答来回、时序过程） | **B 终端抓包** | 读 VIN 对话、刷写全程日志 |
| 单条**报文格式的讲解**（字段逐字节定义） | **C 技术手册** | 0x22 请求/应答字节框图、DTC 状态字节 |

判别法：讲"关系/结构"用 A，讲"过程/交互"用 B，讲"格式/字段"用 C。

## A 工程蓝图（结构图 & 封面）

- 画布：封面 2848×1600，分节图 2400×1350（16:9）
- 底：`#0E2A47` + 80px 白色网格（opacity 0.06）；外框双线（外 3px @0.55、内 1.5px @0.25）
- 线：白色细线为主（`#F4F9FE` 实体、`#DCE9F5` @0.5~0.75 连线），stroke 2~4px，**不发光**
- 填充：节点底 `#0B2440` / 中心体 `#123A63`
- 文字：标题白 `#F4F9FE`（700~800），标签 `#9FC3E8`
- 工程图特征元素（每图至少 1 个）：尺寸标注线（`#7FB2E8` 带端点短线+文字）、四角图纸角标（DWG NO./REV./SHEET）
- 强调色：橙色批注 `#E8A44C`（对应工程图红线批注，仅用于"系列将展开"等高亮，每图 ≤2 处）
- 顶部胶囊改为图纸标题栏样式（左上角文字 `AUTOSAR 入门 ①·UDS` + 细下划线）
- 字体：`'PingFang SC','Hiragino Sans GB',sans-serif`；报文/字节用 `'SF Mono','Menlo',monospace`

## B 终端抓包（交互分析）

- 底：`#0D1117`；终端窗 `#090C10` 圆角 24，边 `#30363D` 3px，标题栏 `#161B22` + 三色圆点（`#DD4B4B/#D29922/#3FB950`）
- 文字全部等宽：`'SF Mono','Menlo','Courier New',monospace`
- 报文行格式仿 candump：`(时间) can0 TX 7E0 [3] 22 F1 90  # 注释`
- 配色：命令/请求绿 `#3FB950`、应答蓝 `#79C0FF`、错误红 `#FF7B72`、注释灰 `#6E7781`、时间戳 `#8B949E`
- 中文标题（文章小节语境）用 `'PingFang SC'` 放在窗口上方，绿色 `$` 命令行样式引出
- 底部可加状态栏（`#161B22` 圆角框）：`─ KEY: val ──` 串联一行汇总信息 + 光标块 `▮`

## C 技术手册（格式讲解）

- 底：`#F7F5F0`（米白）；页眉双线（粗 `#1B3A6B` 5px + 细 2px），页眉左标题右标准号
- 双色：深蓝 `#1B3A6B`（结构/表头/实体）+ 橙 `#B3541E`（强调/数据/箭头），辅灰 `#3D4A5C`/`#8A94A6`
- 字节框：方格 280×130，stroke 4px 深蓝；**正应答 SID 格用深蓝实心反白**；数据载荷用橙虚线框
- 标注：字段下方细引线 + 居中小字（32~36px）
- 图注编号：`Figure N` / `Table N`（深蓝粗体）+ 右侧灰细线，模仿标准原文件式样
- 表格：表头深蓝实心反白，斑马纹 `#FFFFFF`/`#F0EDE4`
- 字体：`'Songti SC','Noto Serif SC','PingFang SC',serif`（衬线的规范感）；页脚 `N / 7` 期号
- 注意：浅底图在公众号暗色模式观感偏灰，仅用于"必须看清字段格子"的格式图

## 通用约定

- SVG 源稿存文章 `img-src/`，渲染 `node .claude/skills/write-article/scripts/render-img.js <in.svg> [out.jpg]`
- 命名：`cover.jpg` + `NN-关键词.jpg` 递增；B 风格图关键词带 `-trace`，C 风格带 `-format` 便于检索
- 三种风格禁止混排于一张图；同一篇文章可三种都用，按小节功能各归各位
- 期号（②~⑦）在 A 风格结构图上用橙色批注标注"本篇主角"位置，形成系列呼应
